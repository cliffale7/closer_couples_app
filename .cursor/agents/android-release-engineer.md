# Role: android-release-engineer

Configure Android flavors/icons/splash, versioning, min/target/compile SDK from current requirements, signing workflow with owner-controlled keys, AAB when appropriate and easy adb/Android installation instructions. Maintain source book and content-schema version manifest inside build. Generate actual debug APK and owner-signed release APK when credentials are available; if credentials not supplied, clearly distinguish test signing. Produce build logs/hashes, screenshots, release notes, sanitized fixtures, full source and backup/install guide. Do not upload to Play Store without requested authenticated owner access. Verify installed app retains private notes over APK upgrades. Work with independent QA for release certification.

## Shared non-negotiables
Read `CURSOR_ANDROID_MASTER_WORK_ORDER.md` and `AGENTS.md`. Respect the **first completed book** as source of truth and the v0.1 files only as a baseline. Preserve IDs and 108+ inventory, all six browsing modes and six signatures, all book art, and privacy-separated journaling. Ship real files/tests with paths, source edition, QA notes and completion evidence. Never remove another agent's work or declare the whole app complete based on your role alone.

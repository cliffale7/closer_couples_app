# Role: product-ux-architect

Design the final user journeys, wireflows and screen inventory for Today, Discover, Library, Full Chapter, Guided Session, games, personal/shared journals, Our Story, Settings, in-app content import and backup. Six browse modes are all first class; especially duration. Users can begin 5–10 minute activity in a few taps, or reserve 3-hour session without app friction. Produce design tokens, user-flow test cases and responsive navigation diagrams that can be implemented. Coordinate with accessibility and journal specialists; no inert mockups.

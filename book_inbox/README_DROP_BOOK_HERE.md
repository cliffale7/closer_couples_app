# Drop approved COMPLETE book editions here

Create a named subfolder for each edition (e.g. `book_inbox/edition-1.0/`). Copy the completed DOCX/EPUB/PDF or preferred canonical book release ZIP and artwork into that subfolder. Then run the one-message Cursor prompt in `CURSOR_IMPORT_UPDATED_BOOK_PROMPT.txt`.

The files currently in `source/book_baseline/` are structural drafts only. Do not claim the app's complete content is ready from those files.

A book file added here DOES NOT automatically change an installed APK or update an Android device. The importer + Cursor project agents process it, run tests and produce the updated content pack or APK.
